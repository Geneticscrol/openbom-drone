# OpenBOM-Drone

A **5-inch FPV shopping list** that also adds grams.

Tick motors, frame, VTX, packs. See example ₹ and whether you blew the weight budget. Edit `data/catalog.json` when your local Robu price is different.

Prices in the catalog are **examples**, not a live store.

## Run

```bash
git clone https://github.com/Geneticscrol/openbom-drone.git
cd openbom-drone
python -m openbom
```

Open http://127.0.0.1:8790

## Tests

```bash
python -m pytest
```
