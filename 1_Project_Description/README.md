# 1 · Project description

**Name:** Kite-5
**Goal:** One reference 5-inch build an Indian club pilot can copy, weigh, and flash without a forum thread.

In: frame, 2207 motors, 5in props, AIO, ELRS, analog VTX, 4S, mass + induced power.
Out: live store prices, digital goggle stacks as the default, autopilots.

Success: kitchen-scale AUW within 40 g of the sheet; hover current in the same band as `hover_power.py`.
